• **[DVLD – Driving and Vehicle License Department System](https://github.com/Iyed-Rb/DVLD)**  
A complete Windows Forms application for managing driving license operations with a structured, multi-layered architecture.

**🔹 Key Features**
- Applicant registration, license issuance, renewals, and test scheduling  
- Support for multiple license classes and application types  
- Tracks application status and manages administrative workflows  

**⚙️ Technical Overview**
- Language: C#  
- UI: Windows Forms (WinForms)  
- Architecture: 3-Tier (Presentation, Business Logic, Data Access)  
- Data Access: ADO.NET  
- Database: Microsoft SQL Server (local setup)  

**🧩 System Design**
- Presentation Layer: User interface and event handling  
- Business Logic Layer: Core processing, validation, and operations  
- Data Access Layer: Database communication via ADO.NET
